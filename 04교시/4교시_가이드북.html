학습 목표

한 토큰에서 역할별 Q·K·V를 구하고, 각 헤드 결과의 행과 열이 뜻하는 것을 설명합니다.

2교시에서 만든 X에는 토큰과 위치의 정보가 함께 들어 있습니다. 오늘은 그 X로 두 헤드의 Q·K·V를 만듭니다.

수학 기초 부록 4절 · 투영과 두 헤드에서 오늘의 계산을 예제로 복습할 수 있습니다.

중요 개념

‘나는 매일 커피를 마신다’에서 ‘마신다’가 어떤 단어를 참고하면 도움이 될까요? 무엇을 마시는지 알아보려면 ‘커피를’이 좋은 후보입니다. 이 문장은 각 역할을 떠올리기 위한 예입니다. 실제로 얼마나 참고할지는 다음 교시에서 숫자로 계산합니다.

한 토큰에서 만드는 세 가지 벡터
이름하는 일예문에서 읽는 법
Q · Query
질의		지금 토큰이 어떤 정보를 참고할지 비교하는 데 쓰는 숫자 묶음입니다.‘마신다’의 Q를 비교의 출발점으로 삼습니다.
K · Key
키		다른 토큰의 Q와 비교될 때 쓰는 숫자 묶음입니다.‘커피를’의 K를 포함해 각 토큰의 K를 ‘마신다’의 Q와 하나씩 비교합니다.
V · Value
값		얼마나 참고할지가 정해진 뒤, 그 비율에 따라 섞어 가져올 숫자 묶음입니다.‘커피를’을 많이 참고한다면 그 토큰의 V가 결과에 더 많이 반영됩니다.

Q와 K를 비교해 점수 만들기(5교시) → 점수를 비율로 바꾸기(6교시) → 그 비율로 V를 섞기(7교시)

문장 속 모든 토큰에서 Q·K·V를 각각 만듭니다. 위에서 ‘마신다’를 출발점으로 삼았지만, ‘커피를’도 자기 Q로 다른 토큰의 K를 비교할 수 있습니다.

헤드(Head)는 무엇인가요?

같은 문장을 두 번 살펴본다고 생각해 보세요. 헤드 하나는 문장 전체를 받아, 자기 방식으로 어떤 토큰을 참고할지 정하고 그 정보를 섞는 계산 한 묶음입니다. 두 헤드가 있으면 각각 자기 Q·K·V를 만들어 이 계산을 따로 합니다.

실습에서는 두 헤드 모두 같은 네 토큰을 읽습니다. 예를 들어 ‘나는’의 입력 [0, 0, 1, 1]에서 Head 1은 앞의 [0, 0]을, Head 2는 뒤의 [1, 1]을 골라 각각 계산에 씁니다. 실제 모델은 헤드마다 학습한 가중치가 달라 같은 문장에서 다른 단서를 살필 수 있습니다.

두 헤드가 계산을 마치면 같은 토큰의 결과를 한 줄에 나란히 놓습니다. ‘나는’의 Head 1 결과 두 값 뒤에 ‘나는’의 Head 2 결과 두 값을 붙이는 식입니다. 자세한 흐름을 다음 그림에서 확인해 보세요.

왜 하나요?

무엇을 찾는지, 무엇과 비교할지, 무엇을 가져올지를 구분하면 같은 토큰도 역할에 따라 다르게 표현할 수 있습니다.

무엇을 하나요?

같은 X의 각 행에 헤드별 Q용·K용·V용 가중치를 따로 곱합니다. 가중치 한 열에서 결과 한 성분이 나옵니다.

그림 · Q·K·V의 흐름과 두 헤드의 크기

손계산 예제

원논문 §3.2.2(PDF 5쪽)의 MultiHead 식에서 Q·K·V는 투영 전 입력입니다. 인코더 자기 어텐션에서는 세 입력 모두 같은 X에서 출발합니다. 수업의 Q(j)·K(j)·V(j)는 X에 각각 WQj·WKj·WVj를 곱한 뒤의 행렬입니다. 논문의 헤드 번호 i와 여기서 쓰는 j는 같은 역할입니다.

학습은 Q·K·V용 가중치를 각각 조정합니다. 아래는 그 구조를 손으로 따라가기 위해 수업에서 정한 가중치입니다. 각 열의 숫자 네 개를 입력 행과 같은 순서로 곱해 더합니다. 예를 들어 첫째 열 [2, 0, 0, 0]은 1×2 + 1×0 + 0×0 + 0×0을 뜻합니다.

Head 1 · ‘마신다’ 입력 [1, 1, 0, 0]

화면용 가중치 표 1 · Head 1의 가중치
입력 성분WQ 열 0WQ 열 1WK 열 0WK 열 1WV 열 0WV 열 1
d0200.5010
d10400.2501
d2000000
d3000000

가중치 표의 크기　4행은 입력 성분 d0~d3입니다. Q용·K용·V용 가중치가 각각 2열이라 나란히 놓으면 4×6입니다. X에 곱해 나온 Q·K·V의 4행은 각각 토큰 4개를 뜻합니다.

역할성분 0 계산식성분 1 계산식
Q1×2 + 1×0 + 0×0 + 0×0 = 21×0 + 1×4 + 0×0 + 0×0 = 4
K1×0.5 + 1×0 + 0×0 + 0×0 = 0.51×0 + 1×0.25 + 0×0 + 0×0 = 0.25
V1×1 + 1×0 + 0×0 + 0×0 = 11×0 + 1×1 + 0×0 + 0×0 = 1

같은 ‘마신다’ 행에서도 Q는 [2, 4], K는 [0.5, 0.25], V는 [1, 1]입니다. 다른 가중치로 만들었기 때문입니다.

Head 2 · ‘마신다’ 입력 [1, 1, 0, 0]

화면용 가중치 표 2 · Head 2의 가중치
입력 성분WQ 열 0WQ 열 1WK 열 0WK 열 1WV 열 0WV 열 1
d0000000
d1000000
d2200.5010
d30400.2501

가중치 표의 크기　4행은 입력 성분 d0~d3입니다. Q용·K용·V용 가중치가 각각 2열이라 나란히 놓으면 4×6입니다. X에 곱해 나온 Q·K·V의 4행은 각각 토큰 4개를 뜻합니다.

역할성분 0 계산식성분 1 계산식
Q1×0 + 1×0 + 0×2 + 0×0 = 01×0 + 1×0 + 0×0 + 0×4 = 0
K1×0 + 1×0 + 0×0.5 + 0×0 = 01×0 + 1×0 + 0×0 + 0×0.25 = 0
V1×0 + 1×0 + 0×1 + 0×0 = 01×0 + 1×0 + 0×0 + 0×1 = 0

‘마신다’의 Head 2가 모두 [0, 0]인 것은 이 토큰의 d2와 d3가 둘 다 0이기 때문입니다. 예를 들어 ‘나는’은 Head 2에서 Q=[2, 4], K=[0.5, 0.25], V=[1, 1]이 됩니다. 가중치가 달라도 특정 입력에서는 같은 값이 나올 수 있습니다.

원논문의 Transformer에서는 어떻게 하나요?

원논문의 각 헤드는 역할별 가중치를 학습합니다. 토큰 네 개와 헤드당 두 성분은 손계산 설정입니다.

Transformer 원논문 3.2.2절 Multi-Head Attention (arXiv PDF 4~5쪽 [오프라인 4쪽] · 헤드별 투영식은 5쪽 [오프라인 5쪽]) · 각 헤드에서 Q·K·V에 별도의 가중치를 곱하는 식을 확인할 수 있습니다.

워크시트 실습

이제 워크시트 인쇄물을 꺼내 실습해 봅시다. ①에서 Q·K·V 각각의 행과 열이 무엇을 세는지 설명한 뒤, ②와 ③은 ‘커피를’의 같은 X 행을 사용해 각 역할의 두 열을 따로 계산합니다. ④는 같은 토큰의 두 헤드 Q만 순서대로 옮기고 X와 비교합니다. ⑤는 숫자가 달라진 이유를 설명합니다. 워크시트에서 Head 1은 참조표 B-1, Head 2는 B-2를 보세요.
