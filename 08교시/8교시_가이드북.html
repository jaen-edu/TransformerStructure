학습 목표

잔차 연결과 층 정규화의 이유를 설명하고, 한 토큰 행을 두 번째 정규화까지 계산합니다.

인코더(Encoder)는 원문의 각 토큰을 다음 단계에서 쓸 수 있도록 정리합니다. 2교시에서 만든 X는 토큰과 위치 정보가 담긴 입력 표입니다. U는 7교시의 셀프 어텐션(Self-Attention) 출력에 붙인 수업용 기호입니다. 두 헤드의 결과를 이어 붙이고 출력 가중치 WO를 곱한 표이며, 원논문 3.2.2절의 MultiHead 계산 결과에 해당합니다. 두 표에서 한 행은 토큰 하나, 네 열은 그 토큰 벡터의 네 성분입니다.

중요 개념

잔차 연결은 입력을 보존하는 직접 경로와 계산 결과를 더하는 방식입니다. 층 정규화는 토큰 한 행의 성분을 기준으로 값의 중심과 크기를 조절합니다.

왜 원래 입력을 다시 더할까요?

잔차 연결(Residual Connection)은 원래 입력이 다음 단계로 직접 갈 수 있게 하고, 계산한 변화량을 거기에 더하는 방식입니다. 여기서는 U를 X에 더할 변화량으로 봅니다. 정답과의 차이를 따로 구하는 단계 없이, 이미 만든 U를 더하면 됩니다. 예를 들어 원래 값이 2이고 변화량이 −1이면 결과는 1입니다. 변화량이 0인 칸은 원래 값이 그대로 남습니다. 이 직접 경로는 여러 층을 쌓았을 때 학습 신호가 앞쪽으로 전달되는 데도 도움이 됩니다.

X와 U에서 같은 토큰 행과 같은 성분 열의 값을 더한 표를 R이라고 부릅니다. 식으로 쓰면 R = X + U입니다.

왜 층 정규화를 할까요?

층 정규화(Layer Normalization, LayerNorm)는 한 토큰 벡터의 평균을 빼서 중심을 옮기고, 표준편차(값이 얼마나 퍼져 있는지를 나타내는 수)로 나누어 크기를 조절합니다. 예를 들어 [1, 3]과 [10, 30]은 같은 비율로 벌어져 있지만 숫자 크기는 다릅니다. 각 행에서 평균을 빼고 자기 표준편차로 나누면 둘 다 [−1, 1]입니다.

어텐션이나 덧셈을 거치면서 값의 중심이나 크기가 달라질 수 있습니다. 정규화 없이 이런 변환이 여러 층에서 이어지면 다음 계산에 들어가는 값이 지나치게 커지거나 작아져 학습이 불안정해질 수 있습니다. 층 정규화는 각 토큰 벡터를 일정한 기준에 맞춰 다음 단계에 넘기는 데 도움을 줍니다. R을 정규화한 표를 N이라고 부릅니다.

무엇을 하나요?

X와 U를 더해 R을 만들고 층 정규화로 N을 구합니다. N에 순전파 신경망(Feed-Forward Network, FFN)을 적용한 결과를 다시 N에 더하고, 그 새 합을 정규화합니다.

손계산 예제

워크시트와 다른 숫자로 한 토큰만 끝까지 따라가 봅시다. X의 한 행이 [0, 1, 1, 2], U의 같은 행이 [0, 1, 1, 2]라면 같은 칸끼리 더한 R은 [0, 2, 2, 4]입니다.

  1. 평균은 네 값의 합을 4로 나눈 2입니다.
  2. 각 값에서 평균을 뺀 값이 편차입니다. 이 행의 편차는 [−2, 0, 0, 2]입니다.
  3. 편차를 각각 제곱하고 그 평균을 내면 분산입니다. (4 + 0 + 0 + 4) ÷ 4 = 2입니다.
  4. 분산의 제곱근인 표준편차는 √2입니다. 네 편차를 각각 √2로 나누면 N은 [−√2, 0, 0, √2]입니다.

실제 층 정규화에서는 분모가 0이 되는 것을 막는 작은 수를 분산에 더하고, 정규화 뒤에는 학습한 배율과 이동값을 적용할 수 있습니다. 손계산에서는 분산이 양수인 행을 사용하고, 작은 수는 생략하며 배율과 이동값은 1과 0으로 둡니다.

FFN에서 무엇을 하나요?

어텐션은 다른 토큰에서 어떤 정보를 가져올지 계산합니다. 순전파 신경망(Feed-Forward Network, FFN)은 그렇게 얻은 정보를 포함한 각 토큰의 벡터를 한 행씩 다시 처리합니다. 모든 행에 같은 가중치를 적용하면서, 각 행의 성분을 섞거나 바꿔 다음 단계에서 쓸 표현을 만듭니다. 구현 코드에서는 이 부분을 다층 퍼셉트론(Multilayer Perceptron, MLP)이라고도 부릅니다.

첫 번째 가중치 W₁으로 성분을 섞고, 정류 선형 함수(Rectified Linear Unit, ReLU)로 음수는 0으로 바꾸고 0과 양수는 그대로 둡니다. 이렇게 입력의 부호에 따라 작동이 달라져 두 가중치만 연달아 곱할 때보다 다양한 변환을 할 수 있습니다. 두 번째 가중치 W₂를 곱한 결과를 F라고 부릅니다. F는 FFN의 출력 표입니다. 실제 Transformer는 학습 과정에서 W₁과 W₂의 값을 조정합니다.

FFN 안에서 성분 수는 어떻게 바뀌나요?

아래 숫자는 토큰 하나의 벡터에 들어 있는 성분 수입니다. W₁은 입력을 FFN의 내부 폭으로 바꾸고, ReLU는 각 칸의 값만 바꿉니다. W₂는 결과를 원래 폭으로 되돌립니다.

숫자 예제 · 2 → 4 → 2

입력 [a, b] = [2, 3]에서 시작합니다. 첫 번째 가중치 W₁은 2×4 행렬입니다. 각 열의 두 가중치를 a와 b에 곱해 더하면 내부 성분 하나가 나옵니다.

W₁의 열 (a, b 순)ReLU 전ReLU 후
첫째 [1, 1]a + b = 2 + 3 = 55
둘째 [1, −1]a − b = 2 − 3 = −10
셋째 [−1, 1]b − a = 3 − 2 = 11
넷째 [2, −1]2a − b = 2 × 2 − 3 = 11

ReLU는 음수인 둘째 값 −1만 0으로 바꿉니다. 그래서 내부 네 성분은 [5, 0, 1, 1]입니다.

두 번째 가중치 W₂는 4×2 행렬입니다. 내부 네 성분에 각 열의 가중치를 같은 순서로 곱하고 더하면 출력 한 성분이 나옵니다.

  • 첫째 열 [1, 0, 0, 0]을 적용하면 5×1 + 0×0 + 1×0 + 1×0 = 5입니다. 입력 두 값의 합을 가져옵니다.
  • 둘째 열 [0, 1, 1, 1]을 적용하면 5×0 + 0×1 + 1×1 + 1×1 = 2입니다. ReLU를 거친 두 방향의 차이와 넷째 값을 더합니다.

이 예에서 가중치는 계산을 보여 주려고 정했습니다. 출력은 [5, 2]입니다. 입력과 출력이 모두 두 성분이므로 잔차 연결에서 같은 번호끼리 더할 수 있습니다. 워크시트에서는 기존의 네 성분 입력과 4 → 4 → 4 계산을 사용합니다.

손계산용 가중치. 실습에서는 W₁을 곱해도 입력이 그대로 나오는 항등행렬로 두고, W₂는 첫째 성분 d0과 넷째 성분 d3만 맞바꾸도록 정했습니다. 이렇게 하면 ReLU에서 어느 값이 0이 되고, W₂에서 어느 값이 자리를 옮기는지 한 단계씩 쉽게 확인할 수 있습니다. 앞에서 구한 N의 한 행으로 따라가 봅시다.

단계같은 토큰의 네 성분
W₁ 적용 직후[−√2, 0, 0, √2]
ReLU 적용 직후[0, 0, 0, √2]
W₂ 적용 직후 · F[√2, 0, 0, 0]

왜 FFN 뒤에도 더하고 정규화할까요?

FFN도 입력을 바꾸는 별도의 계산입니다. 그래서 FFN에 들어갔던 N이 직접 지나갈 길을 두고, FFN이 만든 변화 F를 더합니다. 그 합을 S라고 부릅니다. S = N + F입니다. 이 예에서는 [−√2, 0, 0, √2] + [√2, 0, 0, 0] = [0, 0, 0, √2]입니다. N과 S는 값의 중심과 퍼진 정도가 달라졌으므로 S를 다시 정규화합니다.

원논문 3.1절의 LayerNorm(x + Sublayer(x))에서 x는 그 계산에 들어가기 직전의 입력, Sublayer(x)는 그 계산의 결과입니다. 어텐션에서는 X와 U, FFN에서는 N과 F가 이 자리에 들어갑니다. 같은 구조를 두 번 쓰지만, 더하는 입력과 결과는 단계마다 다릅니다.

두 번째 LayerNorm에서 다시 구할 값

첫 번째에는 R의 한 행을, 두 번째에는 S의 한 행을 읽습니다. 같은 예에서 R의 평균은 2였지만, S = [0, 0, 0, √2]의 평균은 √2 ÷ 4 ≈ 0.35입니다. S에서 2를 빼면 평균이 0이 되지 않습니다. 그래서 계산 순서는 그대로 쓰고, 평균과 분산은 S의 네 성분으로 새로 구합니다.

  1. 편차 구하기. S의 네 성분에서 모두 같은 평균 √2/4를 뺍니다.
    • 첫째·둘째·셋째 성분은 모두 0이므로 각각 0 − √2/4 = −√2/4입니다.
    • 넷째 성분은 √2입니다. 분모를 4로 맞추면 √2 = 4√2/4입니다.
      √2 − √2/4 = 4√2/4 − √2/4 = 3√2/4
    편차를 첫째부터 넷째까지 순서대로 쓰면 [−√2/4, −√2/4, −√2/4, 3√2/4]입니다.
  2. 편차를 제곱하면 [1/8, 1/8, 1/8, 9/8]입니다. 네 값의 평균인 분산은 3/8이고, 표준편차는 √(3/8)입니다.
  3. 표준편차 √(3/8)은 약 0.61입니다. 첫째 칸은 (−√2/4) ÷ √(3/8) ≈ −0.58입니다. 나머지 편차도 같은 표준편차로 나누면 약 [−0.58, −0.58, −0.58, 1.73]입니다.

H는 두 번째 층 정규화까지 마친 인코더 출력 표에 붙인 수업용 기호입니다. 원논문 그림 1에서 인코더 전체의 맨 위를 떠나 디코더로 전달되는 최종 출력에 해당합니다. 논문은 인코더 층을 여러 개 쌓고, 실습에서는 한 층의 계산을 따라갑니다.

워크시트에 나오는 기호
X(원래 입력) + U(어텐션 결과) → R(첫 합) → 층 정규화 → N
N(FFN 입력) → FFN → F(FFN 결과)
N + F → S(둘째 합) → 층 정규화 → H(인코더 출력)

원논문의 Transformer에서는 어떻게 하나요?

원논문은 어텐션 뒤와 FFN 뒤에 각각 잔차 연결과 층 정규화를 적용합니다.

워크시트 실습

이제 8교시 워크시트 인쇄물을 꺼내 실습해 봅시다. 1쪽 ①에서 참조표 A의 X와 B의 U를 같은 칸끼리 더합니다. 2쪽 ②는 R의 ‘나는’ 행 네 값으로 시작하고, ③은 N의 각 행에 FFN을 적용합니다. 3쪽 ④에서 N과 F를 더하고, ⑤에서는 S의 ‘나는’ 행 네 값으로 평균과 분산을 새로 구합니다. ①~⑤는 모두 ‘나는’ 행부터 시작합니다. 중간값의 자릿수는 유지하고 결과표만 소수 둘째 자리까지 적으세요. ⑥에서는 ④에서 더한 두 표와 ③에서 FFN이 읽는 행을 설명합니다.
