10교시 - 원문을 본다 - 가이드북

학습 목표중요 개념왜 하는지무엇을 하는지손계산 예제원논문의 Transformer워크시트 실습풀이 확인다음 교시 연결

학습 목표

  • 왜 Q는 번역 쪽에서, K와 V는 원문 쪽에서 만드는지 설명할 수 있습니다.
  • 번역의 한 위치에서 원문의 각 위치를 얼마나 참고할지 가중치로 구할 수 있습니다.

중요 개념 · 크로스 어텐션

크로스 어텐션(Cross-Attention)은 지금 읽는 번역 위치를 기준으로 원문의 각 위치를 얼마나 참고할지 정하는 계산입니다. 9교시의 D는 지금까지의 번역을 읽은 디코더(Decoder)의 표현 표이고, 8교시의 H는 원문을 읽은 인코더(Encoder)의 출력 표입니다.

Q는 질의(Query)로, 비교의 기준입니다. K는 키(Key)로, 원문의 각 위치를 비교하는 데 씁니다. V는 값(Value)으로, 원문의 각 위치에서 가져올 정보입니다.

왜 원문을 다시 볼까요?

지금까지 쓴 번역은 문장을 어떻게 이어갈지 알려줍니다. 예를 들어 drink까지 썼다면 무엇을 마시는지는 원문을 보고 확인할 수 있습니다. 그래서 번역 쪽 D에서 비교의 기준인 Q를 만들고, 원문 쪽 H에서 비교할 K와 가져올 V를 만듭니다. 원문은 이미 주어졌으므로 네 위치 모두를 비교에 사용합니다.

무엇을 계산할까요?

D에서 Q, H에서 K·V 만들기 → 같은 Q로 원문의 K와 비교하기 → 점수를 참고 비율로 바꾸기 순서입니다. 점수표에서 한 행은 번역 위치 하나, 각 열은 원문 위치 하나에 대응합니다. 이렇게 얻은 비율은 원문의 V를 섞는 데 쓰입니다.

세 가중치는 모두 디코더의 크로스 어텐션 블록에 있습니다. 인코더는 원문을 읽어 만든 H를 디코더에 전달합니다. 디코더의 크로스 어텐션이 자기 쪽의 D로 Q를 만들고, 전달받은 H로 K와 V를 만듭니다.

디코더의 크로스 어텐션 가중치곱하는 입력결과
WQ디코더 표현 DQ · 질의
WK인코더 출력 HK · 키
WV인코더 출력 HV · 값

아래 화살표는 표의 두 번째 열에서 세 번째 열로 이어지는 계산을 보여줍니다. 4교시 인코더 셀프 어텐션에도 같은 이름의 가중치가 있고, 각 블록은 자기 가중치를 따로 갖습니다.

Q는 빨강 실선, K는 파랑 파선, V는 주황 일점쇄선입니다. 흑백에서는 선 모양과 Q·K·V 기호를 함께 사용합니다.

손계산 예제

번역의 한 행과 원문의 두 행에서 Q·K·V 만들기

번역의 drink 위치에서 원문의 ‘커피를’과 ‘마신다’를 얼마나 참고할지 구해 봅시다. 아래 숫자는 설명을 위해 만든 예시입니다. 먼저 번역 한 행에서 Q를 하나 만들고, 원문 두 행에서 각각 K와 V를 만듭니다.

이 손계산에서 첫 번째 헤드의 세 가중치 WQ, WK, WV는 모두 아래 4행 × 2열 선택 행렬로 둡니다. 첫 열은 첫째 성분 d0을, 둘째 열은 둘째 성분 d1을 남깁니다. 실제 모델에서는 역할별 가중치를 학습합니다.

입력 성분결과 첫째 칸결과 둘째 칸
d010
d101
d200
d300

가중치 표 읽는 법. 입력 행의 네 값을 d0부터 d3까지 차례로 적으세요. 결과의 첫째 칸은 표의 첫째 열을 위에서 아래로 읽어, 같은 성분끼리 곱한 네 값을 더합니다. 둘째 칸은 같은 입력 행에 표의 둘째 열을 사용합니다. 1을 곱한 값은 그대로 남고, 0을 곱한 값은 합에 영향을 주지 않습니다.

  • Q · D의 drink 행 [1, 0, 2, 3]. 첫째 칸은 1×1 + 0×0 + 2×0 + 3×0 = 1입니다. 둘째 칸은 1×0 + 0×1 + 2×0 + 3×0 = 0입니다. 따라서 Q = [1, 0]입니다.
  • K · H의 ‘커피를’ 행 [0.20, 0.40, 1, 2]. 첫째 칸은 0.20×1 + 0.40×0 + 1×0 + 2×0 = 0.20, 둘째 칸은 0.20×0 + 0.40×1 + 1×0 + 2×0 = 0.40입니다.
  • V · 같은 H의 ‘커피를’ 행. WV에도 같은 두 열을 쓰므로 첫째 칸은 0.20, 둘째 칸은 0.40입니다. 이 예에서 K와 V의 숫자는 같고, K는 비교에, V는 정보를 섞는 데 씁니다.
  • H의 ‘마신다’ 행 [0, 1, 2, 1]. 같은 규칙을 적용하면 K와 V는 각각 [0, 1]입니다.

같은 Q로 원문의 두 위치를 비교하고 비율 구하기

앞에서 만든 drink의 Q [1, 0]을 그대로 사용합니다. ‘커피를’ 열에서는 K [0.20, 0.40], ‘마신다’ 열에서는 K [0, 1]과 비교합니다. 점수표의 한 행은 같은 Q로 계산합니다. 아래 표의 두 열에서 각각 얻은 스케일 점수를 나란히 놓으면, drink 행의 점수 [0.14, 0.00]이 됩니다.

같은 Q로 하는 계산커피를마신다
내적 · 같은 성분끼리 곱해 더하기1 × 0.20 + 0 × 0.40 = 0.201 × 0 + 0 × 1 = 0
스케일 점수 · √2로 나누기0.20 ÷ √2 ≈ 0.140 ÷ √2 = 0.00
지수값exp(0.14) ≈ 1.15exp(0.00) = 1.00
가중치 · 같은 분모로 나누기1.15 ÷ 2.15 ≈ 0.531.00 ÷ 2.15 ≈ 0.47

5교시처럼 키 벡터의 성분 수가 2개라 내적을 √2로 나눕니다. 이어 6교시의 소프트맥스(Softmax)로 점수를 비율로 바꿉니다. exp는 점수를 지수값으로 바꾸는 계산입니다. 이 예에서는 표에 표시한 지수값을 사용합니다. 두 지수값을 더한 1.15 + 1.00 = 2.15가 두 칸의 공통 분모입니다. 첫째 칸은 1.15를, 둘째 칸은 1.00을 같은 2.15로 나눕니다.

이 비율은 ‘커피를’의 V에 약 0.53, ‘마신다’의 V에 약 0.47을 곱하라는 뜻입니다. 두 V는 각각 [0.20, 0.40]과 [0, 1]입니다. 같은 번호의 성분끼리 계산하면 첫째 성분은 0.53 × 0.20 + 0.47 × 0 ≈ 0.11, 둘째 성분은 0.53 × 0.40 + 0.47 × 1 ≈ 0.68입니다. 따라서 이 예에서 drink가 원문을 참고해 얻은 벡터는 약 [0.11, 0.68]입니다. 워크시트에서는 V를 섞기 전의 가중치까지 구합니다.

원논문의 Transformer에서는 어떻게 계산할까요?

원논문의 Transformer Base에서도 출발점은 같습니다. 디코더의 현재 위치는 원문에 무엇을 물어볼지 정하고, 인코더의 각 원문 위치는 비교할 정보와 가져올 정보를 제공합니다. 실제 모델에서는 다음 토큰을 맞히는 학습 과정에서 헤드마다 질의·키·값에 쓸 가중치의 숫자가 조정됩니다.

  1. 한 헤드의 Q·K·V 만들기. 헤드 번호를 j라고 하면 Q는 디코더 행에 WQj를 곱해 구하고, K와 V는 인코더의 각 행에 WKj, WVj를 각각 곱해 구합니다. 가중치 한 열에 여러 성분의 계수가 있으므로 입력 행의 여러 성분을 곱해 더할 수 있습니다.
  2. 원문을 얼마나 참고할지 정하기. 같은 Q를 원문의 각 K와 내적합니다. Transformer Base에서는 한 헤드의 키 벡터 K에 성분이 64개이므로, 내적을 √64 = 8로 나눕니다. 손계산에서 K의 성분이 두 개라 √2로 나눈 것과 같은 규칙입니다. 성분이 많아지면 내적 점수의 편차가 커질 수 있습니다. 제곱근으로 나누면 점수 차이가 너무 커져 Softmax의 비율이 한 칸에 과하게 쏠리는 것을 줄일 수 있습니다. 그 점수들을 같은 행에서 Softmax로 바꿔 가중치를 얻고, 원문의 V를 그 가중치대로 섞습니다. 이렇게 번역 위치 하나마다 헤드의 결과 벡터가 하나 나옵니다.
  3. 여러 헤드의 결과 합치기. 같은 번역 위치에서 나온 8개 헤드의 64성분 결과를 이어 붙여 512성분을 만든 뒤, 학습한 출력 가중치 WO를 곱합니다. 이렇게 만든 크로스 어텐션 출력은 디코더의 다음 계산으로 이어집니다.
크기 비교가이드북 손계산Transformer Base
한 토큰의 입력 성분 수4512
한 헤드의 역할별 가중치 크기4행 × 2열512행 × 64열
한 헤드에서 Q·K·V 각각의 성분 수264

두 경우 모두 같은 번역 위치의 Q로 원문의 K를 차례로 비교합니다. 위 숫자는 한 벡터의 성분 수입니다. 점수표의 열 수는 비교할 원문 토큰 수로 정해집니다.

워크시트 실습

이제 10교시 워크시트 인쇄물을 꺼내 실습해 봅시다.

  1. ① 1쪽에서 그림의 빨강 실선·파랑 파선·주황 일점쇄선으로 화살표를 그리고 Q·K·V 기호와 출처를 적습니다.
  2. ②의 답은 워크시트 2쪽에 쓰고, 계산에 필요한 값은 워크시트 1쪽의 참조표 A·B에서 찾습니다.
    • 참조표 A · 디코더 표현 D. 번역의 drink 행에서 d0·d1을 읽어 Q로 씁니다.
    • 참조표 B · 인코더 출력 H. 원문 토큰마다 해당 행의 d0·d1을 읽습니다. 이 두 값은 이 실습에서 그 토큰의 K와 V에 각각 쓰입니다.
    같은 drink의 Q를 원문 토큰의 K와 차례로 내적하고 각각 √2로 나눕니다. 결과는 2쪽의 drink 행에 원문 토큰별로 적고, ‘마신다’ 열의 계산식은 따로 남깁니다.
  3. ③ 2쪽에서 ②의 점수를 참조표 C 왼쪽 열에서 찾고, 오른쪽의 지수값을 결과표의 같은 칸에 씁니다. 같은 행의 네 지수값을 더해 그 행의 분모를 구합니다.
  4. ④ 3쪽에서 각 지수값을 같은 행의 분모로 나눕니다. ⑤ drink 행에서 가장 큰 비율을 찾고, ⑥ <BOS>와 I의 Q를 비교합니다.
